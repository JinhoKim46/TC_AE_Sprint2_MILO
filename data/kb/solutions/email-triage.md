# Email triage

The email-triage module reads a shared inbox, labels each message by request type, and drafts a first reply for staff to approve. It is for teams where requests arrive in one mailbox and get lost between other mail.

## What it does

Each new message is read and given a label, such as new job, question, complaint or invoice. The module also sets a priority so that the most pressing messages rise to the top. For each message it drafts a reply in your own wording. A member of staff reads the draft, changes it if needed, and sends it. Nothing goes out on its own.

## What is included

The module includes labels, priority, draft replies and an audit log. The audit log records which message was labelled how, which draft was written and who approved it, so you can always see what happened to a request.

## What is not included

The email-triage module never sends a message without approval. It does not change the mailbox rules, and it does not delete mail. Your inbox stays exactly as it is; the module only adds labels and drafts.

## Connecting it to your tools

The module works with csv-export and api-connector. With csv-export, labelled requests are written to a file for your job tool to import. With api-connector, the module creates the request in your tool directly.

## Price

The base monthly price for email-triage is 390 USD. The setup fee is 900 USD per module. A volume factor applies based on daily request volume, and a monthly surcharge applies for the api-connector integration. All prices are indicative and non-binding.

## Who it suits

Owners who say that jobs get lost in the inbox, or that one person spends the morning sorting mail, usually start with this module. It does not replace the person who answers; it gives them a sorted inbox and a first draft.
