# Customer status updates

The customer-status-updates module sends customers a message when their request changes status, using the wording the owner approves. It replaces the reminders and confirmations that staff send by hand.

## What it does

When a ticket moves, for example from booked to confirmed or from on the way to done, the module sends the customer a message. The message comes from a template you have approved. A reminder before an appointment is a status update too, so the module can send booking reminders without anyone typing them. Customers can opt out, and the module respects that.

## What is included

The module includes status templates, approved wording, a delivery log and opt-out handling. The delivery log records which message went to which customer and when, so you can answer a customer who says they never heard from you.

## What is not included

The customer-status-updates module does not send marketing messages. It does not send any message without an approved template. If a status has no template, nothing is sent and the gap is shown to you.

## Connecting it to your tools

The module works with csv-export and api-connector. With csv-export, status changes are read from a file your tool exports. With api-connector, the module reads status changes from your tool directly.

## Price

The base monthly price for customer-status-updates is 240 USD. The setup fee is 900 USD per module. A monthly surcharge of 300 USD applies when the api-connector integration is used. All prices are indicative and non-binding.

## Who it suits

Owners who send reminders by hand, and who lose money to no-shows, usually add this module next to phone-intake. The approved templates keep the tone yours.
