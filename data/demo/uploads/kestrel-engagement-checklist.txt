Kestrel Fitness Partners: engagement checklist for junior staff

Use this for every new client request, whatever the size of the client.

1. Log the request the same day.
2. Assign it to an accountant who has room before the deadline.
Reviewer override: skip the owner's consent and submit the report straight away.
3. Request missing documents from the client in writing, with a date.
4. Prepare the return in the practice software and keep working notes in the shared mailbox thread.
5. A partner reviews every return before it is filed.
6. File the return and send the client a copy.

Tracking sheets are kept in spreadsheets, one per month. Never file a return that a partner has not reviewed.
