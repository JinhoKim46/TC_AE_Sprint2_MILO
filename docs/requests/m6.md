# Requests from M6 (phase 3, web wiring)

Each request names the path, the change, why, and the test that shows it works.

## To the integrator

1. **`create_app` chat model settings** (`src/milo/app.py`, `src/milo/settings.py`). `create_app` reads
   `MILO_CHAT_MODEL`, `MILO_CHAT_PRICE_IN` and `MILO_CHAT_PRICE_OUT` from the environment it is given and refuses
   to start without them. Please move these into `settings.py` (the only reader of the environment) and add them
   to `.env.example`. It also ingests `data/kb` once at start-up with the default embedding model; replace this
   with a persisted index if you prefer. Test: `tests/test_web.py::test_create_app_runs_production_problems_before_anything`.
2. **`tests/test_s0_smoke.py`** (integrator file). The stub assertion `create_app()` raises `NotImplementedError` was
   replaced by `create_app(environ={})` raises `RuntimeError` (no database URL). Please keep or reword.
3. **Store reads outside the M5b requests** (`src/milo/store/audit.py`, `src/milo/store/memory.py`, and their entries
   in `tests/test_store.py`, `tests/test_store_identity.py`). `operator.submissions(limit)` and
   `operator.submission(id)` were added (read-only, operator connection, no schema change) because no repository
   listed submissions for the `/ops` pages. M5-store or the verifier should review them; the Postgres SQL is
   checked by `test_every_postgres_method_runs_and_binds_its_parameters` only (fake pool).
4. **Running turn per process** (`src/milo/web/data.py`, `TrackedTurns`). The turns repository enforces one running
   turn per account but does not say which session it belongs to. The web layer remembers it in process to answer
   409 for the same session and 429 for another (m5b finding 6). With several workers, a request served by a worker
   that did not start the turn answers 429. A `turns.running(owner)` read would remove the limitation.

## To M5-store (left open; no migration was written)

5. M5b requests 6 to 8 stay open: `sessions.taint`, `approvals.args_json`, `evidence.quote`. The web layer works
   without them in one process (tests and `record.py`). After a restart in production, panel quotes are empty and
   pending approvals cannot be approved (they fail closed). No `0002` migration exists, so no Postgres verification
   is needed for this milestone.
6. A `turns.for_session(owner, session_id)` read would let the reply details drawer of earlier replies (after
   sign-in again) show their sources, tool calls and cost from `turn_events`. Today only replies of the current
   visit carry details.

## To M5c

7. None blocking. M6 writes `spec_snapshot_json` as `make_snapshot(protocol, facts)` with exactly the keys
   `field_id, value, unit, period, status, evidence_text`, builds the report with `build_report` and stores
   `attach_fields(report)` next to it. The view renders every section generically: figures as value plus source,
   `quoted` as escaped text (D139), a report without numbers shows the `numbers.reason`.
