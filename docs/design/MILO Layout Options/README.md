# MILO Layout Options

Design canvas with four layout options for the MILO front end (see `SPEC.md` section 16).

- Published link: https://claude.ai/artifact/Q7iWAKRm9cLV3MjpvZ1EwJ (private; share it from the page's Share menu)
- Local copy: `project/canvas.json` (index) and `project/*.dc.html` (one artboard per option).
  - `Main.dc.html`: option D, inline evidence per turn with an inspector (recommended)
  - `Layout_A.dc.html`: option A, three-column workspace
  - `Layout_B.dc.html`: option B, chat-first with a bottom drawer
  - `Layout_C.dc.html`: option C, multi-page
- Limitation: the artboards need the canvas runtime (`support.js`, served by the platform) to render. The local copy is the source
  only, not a standalone page. Open the published link to see them.
